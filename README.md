
# Rock Scissor Paper Game 🎮

Welcome to the **Rock Scissor Paper Game** repository! This project is an interactive implementation of the classic game loved by many, built with **JavaScript**, **HTML**, and **CSS**. Test your luck and strategy against the computer and enjoy the fun!

---

## 🌟 Features

- 🎲 **Randomized AI Opponent**: Play against a computer that makes random choices.
- ✨ **Dynamic Interface**: Sleek and responsive UI for a seamless experience.
- 📊 **Score Tracker**: Keeps track of wins, losses, and draws.
- 🎨 **Customizable Design**: Easily tweak the design to your liking.
- 🔥 **Fun for All Ages**: A timeless game for everyone to enjoy.

## 🎯 How to Play

1. Choose your move: Rock 🪨, Scissor ✂️, or Paper 📄.
2. The computer will make its choice.
3. The winner is determined based on the rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. Check your score and try to beat the computer!

## 🛠️ Installation and Setup

Follow these steps to run the game locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ashwanik0777/rockScissorPaper_Game.git
   ```

2. **Navigate to the project folder**:
   ```bash
   cd rockScissorPaper_Game
   ```

3. **Launch the game**:
   Open the `index.html` file in your browser.
